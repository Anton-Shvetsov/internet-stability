# Стабильность интернета

Маленький монитор для одного компьютера: раз в минуту проверяет, есть ли интернет и работает ли VPN,
записывает падения в журнал и показывает их на странице `http://<адрес>:8058`.

## Установка

Свой Python не нужен: установщик скачивает проект с GitHub и отдельный Python в папку
`InternetStability` в домашней папке пользователя, затем ставит зависимости из `requirements.txt`
(`fastapi`, `uvicorn`, `httpx`) в `runtime/venv`. Права администратора не нужны, нужен интернет.

- **Windows** (x64): скачайте [`install.bat`](https://raw.githubusercontent.com/Anton-Shvetsov/internet-stability/main/install.bat)
  (правый клик → «Сохранить ссылку как») и запустите двойным щелчком. Python 3.12 с python.org.
- **macOS / Linux** (x86_64 и arm64, Linux с glibc): в терминале

  ```bash
  curl -fsSL https://raw.githubusercontent.com/Anton-Shvetsov/internet-stability/main/install.sh | bash
  ```

  Python 3.12 из [python-build-standalone](https://github.com/astral-sh/python-build-standalone).

**Обновление** — автоматическое: пока монитор запущен, он раз в час проверяет ветку `main` на GitHub,
скачивает новую версию, при необходимости обновляет зависимости и перезапускается за несколько секунд
(в журнал перезапуск не попадает). Если новая версия не запустилась, возвращается старая, а эта версия
больше не ставится. `config.json`, `data/` и скачанный Python не трогаются. Текущая версия видна в шапке
страницы. Частота — `update_check_min` в `config.json` (минуты, от 10 до 1440; `0` — не обновляться).
В клоне репозитория (есть папка `.git`) автообновление выключено.

Вручную — тот же установщик ещё раз (или `install.bat` / `install.sh` из папки установки); так же
установки, сделанные до появления автообновления, получают его. На Windows перед этим закройте окно монитора.

Удалить: закрыть монитор и удалить папку `InternetStability`.

## Запуск

| ОС | Как запустить |
|---|---|
| Windows | двойной щелчок по `start.bat` |
| macOS | двойной щелчок по `start.command` |
| Linux | `~/InternetStability/start.sh` |

Без установщика (например, в клоне репозитория) окружение создаётся вручную, нужен Python 3.9+:

```bash
python3 -m venv runtime/venv
runtime/venv/bin/pip install -r requirements.txt     # Windows: runtime\venv\Scripts\pip ...
./start.sh                                           # Windows: start.bat
```

Открыть страницу: `http://127.0.0.1:8058`, а с других устройств — по адресу, который программа печатает
при старте. Остановить: Ctrl+C или закрыть окно.

Монитор работает, пока открыто его окно. Чтобы он запускался сам, добавьте `start.bat` в автозагрузку
(Windows: `Win+R` → `shell:startup`) или `start.command` в «Объекты входа» (macOS).

## Что проверяется

- **Интернет** — HEAD-запросы к сайтам, доступным без VPN (по умолчанию `ya.ru`, `1.1.1.1`).
- **VPN** — запросы к сайтам, которые открываются **только** через VPN (по умолчанию `telegram.org`,
  `instagram.com`). Эта группа проверяется, только когда есть интернет.

Группа считается живой, если ответила хотя бы одна цель. Падение записывается, когда группа молчит
дольше порога (по умолчанию 3 минуты): короткие моргания сети в журнал не попадают.

Время, когда сам монитор не работал (компьютер выключен или спал, окно закрыто), показано серым как
«не наблюдалось». Падением оно не считается, и в доступность не входит.

В блоке «По дням» каждая полоса — сутки 0–24 ч по времени устройства, на котором открыта страница:
падения стоят на своих часах, и в каждый момент закрашено старшее — монитор не работал → нет интернета →
нет VPN. «Без падений» — сколько прошло с конца последнего падения (остановки монитора его не сбрасывают).

**Проверьте цели VPN один раз:** выключите VPN, и через минуту обе цели VPN в блоке «Последняя проверка»
должны стать ✗, а цели интернета остаться ✓. Если цель VPN открывается без VPN, падения VPN не будут
видны никогда. Если ✗ стали и цели интернета, значит у VPN-клиента включён kill switch.

## Скорость

Если в «Настройках» включить «Измерять скорость загрузки», монитор раз в заданный интервал (по умолчанию
60 минут, от 15 до 1440) скачивает ~10 МБ с `speed.cloudflare.com` и считает скорость загрузки. Это около
240 МБ трафика в сутки при интервале в час. Пока интернета нет, скорость не замеряется. На странице в блоке
«Скорость загрузки» видны последний замер и среднее за каждый день; неудачный замер в среднее не входит.
По умолчанию замер выключен.

## Настройки

Тема страницы переключается кнопкой ☀/☾ в шапке и запоминается в этом браузере; пока её не
трогали, страница следует теме системы.

Цели, интервал и порог меняются на странице, в блоке «Настройки». Они применяются сразу, без перезапуска.
Всё хранится в `config.json`. Адрес и порт сервера (`host`, `port`) правятся только в этом файле,
после правки нужен перезапуск:

```json
{ "host": "0.0.0.0", "port": 8058, ... }
```

`0.0.0.0` открывает страницу всем устройствам локальной сети и Tailscale. Пароля нет: кто видит порт,
тот видит страницу и может менять настройки. Чтобы закрыть доступ снаружи, поставьте `"127.0.0.1"`.

## Файлы

- `data/incidents.json` — журнал падений (хранится 400 дней);
- `data/speed.json` — замеры скорости (хранятся 400 дней);
- `data/state.json` — служебное состояние: когда монитор работал последний раз и последние пробы;
- `data/monitor.log` — лог;
- `data/supervisor.log` — лог запусков и обновлений;
- `runtime/update.json` — установленная версия и версии, откаченные при обновлении.

Чтобы перенести монитор на другое устройство, установите его там установщиком и скопируйте `config.json`.
Папку `runtime` не копируйте: Python в ней собран под свою систему, а пути в `venv` привязаны к старой папке.
Если скопировать и `data`, на новом устройстве останется история старого.
